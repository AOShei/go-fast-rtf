# go-fast-rtf development history

How the library was built, in order. What it does now is in
[`README.md`](README.md); what changed, release by release, is in
[`CHANGELOG.md`](CHANGELOG.md).

Module `github.com/AOShei/go-fast-rtf`, package `gofastrtf`. Extracts RTF
(Microsoft RTF 1.9.1) into the go-fast-core model: one `body` part, and a
`stored` part when the file holds data it never shows. Built on
go-fast-core v0.1.1 (schema 0.2).

## Layout

| Path | What |
|---|---|
| `extract.go`, `doc.go` | Public API: `Extractor`, `Extract`, `ExtractFile`, warning codes, stored kinds |
| `internal/token` | Tokenizer: groups, control words/symbols, text, `\'hh`, bounded `\binN` |
| `internal/codepage` | Code page tables and decoder (moved to go-fast-core's `charset` in v0.3.0): single-byte 874, 1250 to 1258 and 10000, UTF-8 (65001), double-byte 932, 936, 949 and 950 |
| `internal/htmlrtf` | De-encapsulation of HTML from `\fromhtml1` documents ([MS-OXRTFEX]) |
| `internal/reader` | The group/destination state machine that builds the document |
| `cmd/gofastrtf` | The command, printing JSON, Markdown or text |

## Steps

1. **Tokenizer, groups, destinations, code pages.** Group depth limit,
   `\bin` bounded by the decode budget, unknown `\*` destinations skipped,
   `\uN`/`\ucN`, `\'hh` through `\ansicpg`/`\fcharset`/`\cpg`; single-byte
   tables and UTF-8.
2. **Structure.** Paragraphs, headings (`\outlinelevel`, heading styles),
   lists (`\listtext`, `\pntext`, `\ls`/`\ilvl`, list table for ordered vs
   bullet), tables (`\trowd`/`\cell`/`\row`, merges, nested tables
   flattened into their cell), `\line`, `\tab`.
3. **Notes, fields, metadata, pictures, objects.** `\info` metadata;
   footnotes; annotations as comment notes; field results in the text,
   instructions as notes; hyperlinks as spans; `\pict` image blocks;
   `\object`/`\objdata` handed to `Options.Child`.
4. **Stored part, command, fuzzing.** `\*\generator`, `\docvar`,
   `\*\userprops` and text after the closing brace in the stored part;
   `\deleted` as deletion notes; drop-down form fields as `choices` notes;
   `cmd/gofastrtf`, README, `FuzzExtract` and `FuzzLexer`.
5. **Double-byte code pages.** 932, 936, 949 and 950 from `cp9xx.txt`
   tables generated by `internal/codepage/gen/gen_dbcs.py` (Python's
   codecs), parsed lazily into per-lead-byte arrays. Later, the
   user-defined areas of 932 and 936 were computed in code as Windows maps
   them (`internal/codepage/uda_test.go`).
6. **Review.** Budget bounds on held blocks and table rows, the
   custom-property limit, the text of Word 6/95 drawing objects, and a
   corpus test over the public corpus.
7. **Declared, not judged** (core schema 0.2). The library reports only
   what the file declares: `hidden` for `\v` (on the run or through
   `\s`/`\cs` styles and `\sbasedon`) and for a shape's `fHidden`; RTF has
   no `no_ink`. The earlier visibility checks (size, colour, invisible
   characters, proportions) and their warnings were removed; CHANGELOG.md
   lists them. The command took the series' render flags
   (`-exclude-display`, `-stored`, `-part-markers`, `-children`).
8. **Encapsulated HTML.** A document declaring `\fromhtml1` is
   de-encapsulated (`internal/htmlrtf`, a pass before the RTF reading
   that stops at the first content of other documents) and the HTML
   handed to `Options.Child` as `body.html`; when that child gives blocks
   the body gives none. `\fromtext` stays read as RTF.
9. **Field codes as stored data.** Every field note carries
   `Attrs["stored"] = "field_code"`; the command's `-stored[=kinds]`;
   `StoredGenerator`, `StoredCustomProperty` and `StoredKindNames`
   exported.
10. **Thematic breaks.** A break inferred from an empty bottom-bordered
    paragraph (added with step 5) was removed; paragraph borders are not
    read. Word's horizontal line (`fHorizRule`, on a shape or in a
    picture's `\picprop`) gives a native `thematic_break`.

## Not done

- Equations (`\mmath`), for instance their linear text as `formula`
  blocks.
- Computing list numbers when `\listtext` is absent.
- Code pages 437, 850 and Johab (1361).
- A corpus of RTF written by Word, LibreOffice and WordPad to compare
  against.
