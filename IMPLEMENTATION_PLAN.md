# go-fast-rtf implementation plan

Module `github.com/AOShei/go-fast-rtf`, package `gofastrtf`. Extracts RTF
(Microsoft RTF 1.9.1) into the go-fast-core model: one `body` part, and a
`stored` part when the file holds data it never shows. Core pinned at
ebecf3c (v0.0.0-20261120130045-ebecf3cf2089).

## Layout

| Path | What |
|---|---|
| `extract.go`, `doc.go` | Public API: `Extractor`, `Extract`, `ExtractFile`, warning codes |
| `internal/token` | Tokenizer: groups, control words/symbols, text, `\'hh`, bounded `\binN` |
| `internal/codepage` | Single-byte code page tables (1250-1258, 874, 10000) and decoder with DBCS lead-byte handling |
| `internal/htmlrtf` | De-encapsulation of HTML from `\fromhtml1` documents ([MS-OXRTFEX]) |
| `internal/reader` | The group/destination state machine that builds the document |
| `cmd/gofastrtf` | CLI printing JSON, Markdown or text |

## Phases and status

1. **Tokenizer, groups, destinations, code pages** — tokenizer with depth
   limit, `\bin` bounded by the decode budget, `\*` unknown destinations
   skipped, `\uN`/`\ucN`, `\'hh` through `\ansicpg`/`\fcharset`/`\cpg`.
   Double-byte pages (932, 936, 949, 950) are not decoded: U+FFFD per
   character with `text.unmapped_glyphs` naming the code page. Status: done.
2. **Structure** — paragraphs, headings (`\outlinelevel`, heading styles),
   lists (`\listtext`, `\pntext`, `\ls`/`\ilvl`, list table for ordered vs
   bullet), tables (`\trowd`/`\cell`/`\row`, `\clmgf`/`\clmrg`,
   `\clvmgf`/`\clvmrg`, nested tables flattened into their cell), `\line`,
   `\tab`. Status: done.
3. **Notes, fields, metadata, pictures, objects** — `\info` metadata;
   footnotes; annotations as `note` comments; field results in text,
   instructions as `note` blocks; hyperlinks as spans; `\pict`
   image blocks; `\object`/`\objdata` handed to `ExtractChild`. Status: done.
4. **Hidden text** — `\v` and further visibility checks (superseded by
   phase 9), `\deleted` as deletion notes; `\*\generator`,
   `\docvar`, `\*\userprops` and bytes after the document's closing brace in
   the stored part. Status: done.
5. **CLI, README, fuzzing** — `cmd/gofastrtf`, README, `FuzzExtract` and
   `FuzzLexer`. Status: done. Also done: drop-down form fields as `choices`
   notes.

Phases 1 to 4: done (phase-1-rtf branch), tested in `extract_test.go`,
`word_test.go` and the internal packages. The single-byte tables were
checked byte by byte against Python's codecs by the orchestrator.

6. **Phase 2** (phase-2-cjk-breaks branch) — Status: done.
   - Double-byte code pages 932/936/949/950, from `cp9xx.txt` tables
     generated by `internal/codepage/gen/gen_dbcs.py` (Python codecs),
     embedded and parsed lazily into per-lead-byte arrays.
   - (codepage-uda branch) User-defined areas computed in code, not
     tabled: 932 byte 0x80 to U+0080 and leads 0xF0-0xF9 to
     U+E000-U+E757; 936's three areas to U+E000-U+E765, as Windows does.
     949 and 950 unchanged. Boundaries in `internal/codepage/uda_test.go`.
   - Thematic breaks (core df335f0) were inferred from an empty paragraph
     with a styled bottom border; removed on branch `no-inferred-break`
     (no inferred breaks: a border is not a declared break). Paragraph
     borders are no longer read. The declared rule, Word's horizontal-line
     shape (`fHorizRule`, on a shape or in a picture's `\picprop`), gives a
     native `thematic_break` (`TestHorizontalRule`).
   - Character properties set by paragraph and character styles, through
     `\sbasedon` (only `\v` is read now; see phase 9).

7. **Phase 3** (phase-3-hidden-signal branch, core 4de43b1) — Status: done.
   Superseded by phase 9. Field instructions, index/TOC entries (now
   `XE`/`TC` field notes) and the stored part stopped carrying a reason.

8. **Review 1** (review-1 branch, core 17a0e50) — Status: done. Budget
   bounds, the custom-property limit and Word 6/95 drawing-object text
   (all kept), and a corpus test over the public corpus. Its visibility
   rules are superseded by phase 9; CHANGELOG.md lists them.

9. **Declared, not judged** (declared-not-judged branch, core 787b056,
   schema 0.2) — Status: done. **Supersedes the hidden-text parts of
   phases 4, 6, 7 and 8.** The library reports only what the file
   declares: `hidden` for `\v` (direct or through `\s`/`\cs` styles and
   `\sbasedon`); `no_ink`: none in RTF. Removed: the size and colour
   checks (with colour table, `\cbpat`, `\clcbpat`, text-box fill and page
   background reading), the invisible-character scan, the proportion rule,
   `HiddenChecked` and their warnings (CHANGELOG.md lists them). Text after the
   closing brace is stored `after_end` with `input.trailing_data`; white
   space, NUL and `0x1A` alone are ignored, with no byte-count threshold.
   `\webhidden`, field instructions, index/TOC entries and deletions carry
   no reason. See `DECLARED_REPORT_RTF.md` in the workspace root.
   Follow-up decisions (2026-11-20, Andrew): a shape's `fHidden` set to
   true gives its text box and pictures `hidden`; the command has the
   series' render flags (`COMMAND_FLAGS.md`), with `-part-markers`, and `-children` (default
   true, core's `RenderOptions.Children`, added with core 787b056) prints
   embedded documents in Markdown and text.

10. **Encapsulated HTML** (htmlrtf branch) — Status: done. A document
   declaring `\fromhtml1` is de-encapsulated per [MS-OXRTFEX]
   (`internal/htmlrtf`, a pass before the RTF reading that stops at the
   first content of other documents) and the HTML handed to
   `Options.Child` as `body.html`; when that child is extracted the body
   gives no blocks, otherwise the RTF reading stands. The HTML counts
   against the decode budget; past it the child is listed only. Decided by
   Andrew's orchestrator; `\fromtext` stays read as RTF. Details of the
   spec to check: which destinations a de-encapsulating reader skips (here
   the usual RTF ones and every `\*` destination but `\htmltag`, so
   `\*\mhtmltag` too), `\line` as CRLF, and `\htmltag` content written
   even inside an `\htmlrtf` run.

11. **Field codes as stored data** (stored-kinds branch, core ebecf3c).
   Every field note (`\fldinst`, `\xe`, `\tc`, `\tcn`) carries
   `Attrs["stored"] = field_code`, as go-fast-ooxml does, which core's
   `Validate` requires; Markdown and text leave them out by default. The
   command's `-stored[=kinds]` sets `Stored` or `StoredKinds` (core's
   kinds plus `generator` and `custom_property`). Status: done, tested.

## Next, in order

1. Equations (`\mmath`): at least their linear text as `formula` blocks.
2. Computing list numbers when `\listtext` is absent.
3. Code pages 437, 850 and Johab (1361), from generated tables.
4. A small corpus of RTF written by Word, LibreOffice and WordPad, made by
   the user, to compare against.
